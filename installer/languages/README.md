# Inno Setup translation

`ChineseSimplified.isl` is the unmodified Simplified Chinese translation from
the official [Inno Setup 6.7.1 source](https://github.com/jrsoftware/issrc/blob/cfdf48923178df4b4f040e038b423aa555a61ffc/Files/Languages/Unofficial/ChineseSimplified.isl).

- Upstream tag: `is-6_7_1`
- Pinned commit: `cfdf48923178df4b4f040e038b423aa555a61ffc`
- Upstream Git blob: `d6a11c4490de07dad443ade668289fc954dfa1ed`
- Original translator and attribution are retained in the file.
- The accompanying `INNO-LICENSE.txt` retains the upstream license.

The translation is bundled here because the Inno Setup installer does not ship
its unofficial translations. The build extracts this file from the same fixed
project commit as the installer script, with no build-time translation download.
