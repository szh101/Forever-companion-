# addon 0.3.0 快照范围

目标是让 AI 获得尽量广的当前角色背景，仍需尊重客户端公开接口的实际范围。
**这不是完整实时世界状态。** `/fai` 只在用户主动请求且非战斗时读取一次；粘贴后，
助手保存并发送这份快照，游戏中的后续变化不会自动同步。

桌面应用维持 0.4.2，无需重新安装或填写模型设置。addon 安装必须同时复制
`ForeverAI.toc`、`ForeverAI.lua`、`Snapshot.lua` 三个文件到 `AddOns/ForeverAI/`。
已加载 addon 的用户可在方便时手动 `/reload`；新装 addon 需完整重启客户端。

## 导出哪些资料

下表的“可用”均指当前客户端返回非受限值，不保证每个职业、等级或客户端版本都有该字段。

| 类别 | 内容与条件 |
| --- | --- |
| 角色 | 名字、服务器、等级、种族、职业、阵营、经验、休息经验、金币、炉石绑定位置，非战斗时允许读取的生命／资源与基本状态 |
| 角色属性 | 力量等基础属性、护甲、攻击强度、暴击／躲闪／招架／格挡和抗性 |
| 位置 | 区域、子区域、地图 ID、坐标，当前副本与难度 |
| 装备详情 | 装备栏位、物品 ID／链接、本地缓存的名称、品质、等级、类型和耐久 |
| 背包 | 容器与格数、空位、物品 ID／名称／数量／品质／绑定状态 |
| 银行 | 仅银行窗口打开时、当前可见的角色／账号银行页；关闭银行标为未知 |
| 当前任务 | 任务 ID／名称／等级、目标和进度、完成／失败／重复标记、建议队伍人数、接口提供的下一路标；正文仅当前选中任务 |
| 已完成任务 | 客户端返回的已完成任务 ID，不包含每个历史任务的正文 |
| 技能 | 技能线、当前等级、上限、加成；折叠标题可能隐藏内容 |
| 专业 | 当前角色专业名称、等级、上限、技能线 ID |
| 配方 | 仅已打开的当前专业：ID、名称、学习标记、难度、来源类型、产物、数量和材料；其他角色／NPC 制造页不会当成自己的配方 |
| 法术书 | 技能线、法术 ID／名称、被动标记等静态信息，不导出实时冷却循环 |
| 天赋 | 当前配置、天赋树与已激活节点、等级、法术信息 |
| 声望 | 阵营、等级、当前值和等级区间；不自动展开折叠列表 |
| 货币 | 当前列表中的名称、数量、上限及链接；不自动展开标题 |
| 目标 | 当前选中单位公开的基本资料，以及用户主动观察装备的状态／时间；装备沿用根字段 `inspectedEquipment` |
| 队伍 | 当前小队／团队成员的公开名称、等级、职业、职责等基本资料 |
| 当前宠物 | 当前宠物基本资料、种类，以及可用的经验、训练点、快乐／忠诚状态 |
| 商人 | 当前商人窗口中的商品、链接、价格、数量与额外货币标记；未读取全部特殊货币成本 |
| 训练师 | 当前窗口和筛选下的技能、可学状态、费用、等级要求 |
| 飞行点 | 当前飞行管理员地图返回的节点和状态；不等于全球已解锁航线 |
| NPC 对话 | 当前对话文字、可接／活动任务与交互选项文字 |
| 任务对话 | 当前 NPC 任务正文、目标、经验／金钱奖励和可用奖励物品 |
| 坐骑 | 收藏接口报告已拥有的坐骑及可用状态 |
| 收藏宠物 | 收藏列表中已拥有的宠物种类、名称、等级等；不导出收藏 GUID |
| 成就 | 已完成的非公会成就、分数、完成日期、是否当前角色获得；不枚举全部条件进度 |
| 副本进度 | 本地已缓存的副本名称、难度、重置倒计时、锁定状态与首领进度；不主动刷新服务器 |

若要问“银行里的材料够吗”，先打开银行再 `/fai`；要问当前专业配方，先打开自己的该专业。
可以手动展开技能／声望标题、清除配方筛选后再导出以获得更多条目。
**每次导入替换整份快照**，不会把之前银行窗口的旧数据并入新快照。
其他角色、尚未加载窗口、未开放 API 的玩法资料仍未知。装备掉落、配方的具体商人／掉落地点、
任务前置和路线知识需要外部资料，并须匹配快照携带的 Forever 客户端版本。

## AI 怎样判断缺失信息

每类有 `status`、`scope`、`capturedAt`，以及必要的 `reason`／`notes`；`coverage` 汇总状态：

| status | 含义 |
| --- | --- |
| `collected` | 成功得到当前范围内返回的字段；不是承诺整个系统的所有数据都齐全 |
| `partial` | 折叠、筛选、资料未缓存、归属不确定或容量限制；不能用缺失条目证明未拥有／未学会 |
| `requires_window` | 需要用户打开对应游戏窗口，然后重新导出 |
| `unavailable` | 接口不存在、失败或数据受限；未知，不是空列表 |
| `not_applicable` | 当前没有目标、队伍或宠物等适用对象 |

未出现的字段不能解释成 0；`[]` 必须结合状态理解。来源可能是账号共享成就或当前专业视图，
不能一律推断为当前角色已完成／已学习。快照内 `export.completeGameState` 始终为 false，
同时给模型上述语义。角色字段在 `player`，当前任务在 `quests`，不重复复制到类别列表。

## 容量、隐私与兼容性

沿用 `schemaVersion: 1`，保留原有任务、装备与观察字段；现有 Mac / Windows 助手不丢弃新增字段。
助手导入上限仍为 200 KB，addon 为 Python 重序列化空格及元数据预留余量，目标 180 KB。
按类别限制列表条数和字节数；总量仍大时按最大列表削减尾部，并在 `export.omitted` 记录数量。
单类大小／条目上限通过 `notes` 标明，类内 `omitted` 仅统计实际遇到的删减条目，不是未知尾部总数。
每段文字最多 3000 UTF-8 字节；正文可能截短。无法压到复制上限时直接提示重新导出，不能静默准备无法导入的文本。

不存在“所有接口全开”：不扫描任意 Lua 全局表，不把 secret/protected 值转字符串，不读取进程内存。
不读取聊天／私聊、邮件正文、好友／公会名册，不扫描拍卖行或未加载的其他角色。
没有后台轮询、自动观察、任务选择、筛选修改、购买、接受任务、施法或按键模拟。
addon 不保存这些快照；用户复制并发送后，角色名称、服务器、队友名称等已导出游戏资料会随问题
交给用户选择的模型连接，桌面助手本身仍不持久保存对话或快照。
